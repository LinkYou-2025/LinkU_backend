작업 목표:
- 현재 브랜치의 커밋을 원격에 푸시하고, PR 초안을 생성한다.

입력:
- $ARGUMENTS 에 PR 제목 방향, Draft 여부, 라벨 정보가 들어올 수 있다.

반드시 수행할 절차:
1. 현재 브랜치와 원격 추적 상태를 확인한다.
2. 아직 커밋되지 않은 변경사항이 있으면 먼저 중단하고 사용자에게 알린다.
3. 최근 커밋 내역을 요약한다.
4. 필요하면 push 전 최소 검증 항목을 다시 확인한다.
5. 사용자가 승인하면 현재 브랜치를 remote 에 push 한다.
6. .github/PULL_REQUEST_TEMPLATE.md 를 읽고 PR 본문 초안을 작성한다.
7. 아래 항목을 포함해 PR 내용을 구성한다:
    - 변경 배경
    - 주요 변경점
    - 테스트/검증 결과
    - 리뷰 포인트
    - 필요 시 다이어그램 또는 흐름 설명
8. Draft 또는 Ready 상태를 사용자에게 확인한다.
9. 라벨 후보를 제안하고, 사용자가 승인하면 반영한다.
10. 작업자 관점의 셀프 리뷰 코멘트를 작성한다.

제약:
- 승인 없이 push 하지 않는다.
- PR 템플릿 섹션을 임의로 삭제하지 않는다.
- 검증되지 않은 내용을 테스트 완료로 쓰지 않는다.

출력 형식:
- "푸시 결과"
- "PR 제목 초안"
- "PR 본문 초안"
- "라벨/상태 제안"
